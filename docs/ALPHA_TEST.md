# Windows Alpha 两轮试用方案

本方案用于 Desktop Pet 0.2 的真实 Windows 验收。每个测试包都必须记录版本、commit 和测试环境；第一轮阻断问题清零后才能进入第二轮。

## CI 已自动覆盖

当前 Windows runner 会在上传候选包前自动验证：

- 版本一致性、前端/Rust 测试、编译、Clippy 和 npm 高危漏洞审计。
- 便携版为 x86-64 Windows GUI 程序，NSIS 与 SHA-256 文件完整。
- NSIS 在随机隔离目录静默安装，创建主程序、卸载器、HKCU 卸载项和开始菜单快捷方式。
- 已安装主程序启动后持续存活至少 5 秒。
- 静默卸载后安装目录、卸载项和开始菜单快捷方式均被清理。

这些检查能排除构建和基础安装链路错误，但不能证明可见窗口、托盘交互、系统重启或真实传感器体验正常。

## 仍需真机人工确认

- 桌宠和托盘实际可见，窗口透明、置顶、拖动和缩放表现正确。
- 托盘所有入口、鼠标穿透恢复、安静模式、投喂与设置交互正常。
- 开机启动经过真实 Windows 重启后生效，并能再次关闭。
- CPU、空闲、打字速率、持续过载、睡眠与唤醒反应符合预期。
- 多显示器拔插、Windows 睡眠/唤醒、长时间运行与安全软件提示可接受。
- 安装器的中英文界面、未知发布者提示、交互式安装与卸载体验可理解。

## 试用轮次

### 第一轮：功能 Alpha

- 人员：项目维护者 + 1～2 位熟悉项目的测试者。
- 环境：至少一台 Windows 11；可用时补一台 Windows 10。
- 目标：发现启动、托盘、窗口、设置、投喂和退出流程中的阻断问题。
- 放行条件：P0/P1 问题为 0，核心清单全部通过，连续运行 2 小时无崩溃或失控后台进程。

### 第二轮：体验 Beta

- 人员：3～5 位不了解实现细节的试用者。
- 环境：覆盖不同缩放比例；至少一位测试者使用双显示器。
- 目标：验证可理解性、默认行为、隐私说明和日常常驻体验。
- 放行条件：P0/P1 问题为 0，P2 有明确结论，安装版与便携版均完成冒烟测试。

## 核心测试清单

记录每项为 `通过 / 失败 / 不适用`，失败时附截图、复现步骤和日志。

### 启动与退出

- 首次启动出现托盘图标和桌宠窗口。
- 重复启动不会留下多个失控实例。
- 托盘退出后窗口消失，任务管理器中进程结束。
- 便携版在含中文和空格的路径下可以启动。
- 两个 EXE 的 SHA-256 与 `SHA256SUMS.txt` 一致。

### 窗口与托盘

- 桌宠可拖动，重启后恢复位置。
- 移除副显示器后，桌宠回到可见屏幕。
- 100%、125%、150% 缩放下布局可用。
- 隐藏、显示、投喂、设置、安静模式、鼠标穿透和退出菜单可用。
- 开启鼠标穿透后，可以从托盘关闭穿透并恢复交互。

### 设置与隐私

- 外观、安静模式、三个检测开关、鼠标穿透和开机启动重启后保留。
- 关闭单项检测后，对应读数显示“已关闭”。
- 安静模式暂停普通检测和动画，但投喂仍有反应。
- 设置文件损坏时应用可启动，设置页显示恢复提示；保存后提示消失。
- 恢复默认会关闭开机启动和鼠标穿透、恢复默认外观并重置窗口位置。
- 隐私说明明确：不记录按键内容、不读取文件正文、不上传数据。

### 状态与投喂

- 普通状态变化没有明显闪烁。
- 高负载未持续 10 秒时不进入过载；持续后进入过载，负载下降后恢复。
- 2 分钟空闲进入犯困，5 分钟进入睡眠，恢复输入后唤醒。
- 代码、图片、压缩包、大文件和未知文件得到正确反馈。
- 投喂只展示文件元信息，不修改原文件。

### 开机启动与长期运行

- 开启开机启动后重启 Windows，应用自动运行一次。
- 关闭开机启动后再次重启，应用不再自动运行。
- 睡眠/唤醒后托盘、桌宠和传感器继续工作。
- 连续运行期间 CPU 与内存没有持续异常增长。

### NSIS 安装与卸载

- 当前用户安装不要求管理员权限。
- 开始菜单快捷方式能启动正确版本。
- 同版本覆盖安装后本机设置仍保留。
- 尝试用旧版本覆盖新版本时被阻止。
- 卸载后应用文件和快捷方式被移除，用户设置保留策略符合发布说明。

## 问题等级

- P0：数据损坏、安全/隐私越界、系统无法正常使用。
- P1：无法启动或退出，核心入口失效，鼠标穿透无法恢复，稳定复现崩溃。
- P2：功能可绕过但明显影响体验或判断。
- P3：视觉、文案和低频细节问题。

## 每轮记录

每轮结束后在发布记录中写明：

- 测试包 commit 与下载来源。
- 参与人数和覆盖环境。
- 通过、失败和未测项目。
- 已修复问题及剩余已知问题。
- 是否满足进入下一轮或公开发布的放行条件。
